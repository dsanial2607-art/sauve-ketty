SAUVE KETTY — PATCH COMPATIBILITE KETTYBOT

Corrections :
- JavaScript réécrit pour ancien WebView Android (ES5)
- suppression de play().catch() qui peut faire planter un ancien navigateur
- sons OGG convertis en MP3
- son joué immédiatement pour une mauvaise lettre
- grandes images accueil/victoire/défaite optimisées en JPG (~600 Ko au lieu de ~3,5 Mo)
- suppression du backdrop-filter de l'accueil
- animation de fin simplifiée et compatible (fondu + zoom)
- conservation de speechSynthesis lorsqu'il existe

IMPORTANT VOIX :
Si le WebView du KettyBot ne fournit pas speechSynthesis / une voix française Android,
aucun code web ne peut créer cette voix localement. Le jeu reste fonctionnel et affiche
les phrases. Pour garantir une vraie voix sur KettyBot, il faudra ajouter des fichiers
MP3 de voix préenregistrée ; le code peut ensuite les lire comme les effets sonores.

Installation : remplacer le contenu du dépôt GitHub sauve-ketty par le contenu de ce ZIP.
Conserver la même structure de dossiers.
