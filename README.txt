SAUVE KETTY — VERSION FINALE

Contenu :
- Image d'accueil : Accueil.png
- Image de victoire : Bravo.png
- Image de défaite : perdu.png
- 16 mots configurés :
  facteur, viarhona, ceramique, labyrinthe, baignade, palais, poire, rhone, lama, accrobranche, escargot, chevre, fruits, velo, randonner, vignoble

MODE VISITEUR
- Ouvrir simplement index.html
- Le bouton PARAMÈTRES n'apparaît pas.

MODE ADMINISTRATION
- Ajouter ?admin=1 à l'adresse.
  Exemple :
  https://votre-site.github.io/sauve-ketty/?admin=1
- Le bouton PARAMÈTRES réapparaît alors pour modifier les mots et les images.

DÉPLOIEMENT GITHUB PAGES
1. Remplacer les anciens fichiers du dépôt sauve-ketty par le contenu de ce dossier.
2. Conserver index.html à la racine du dépôt.
3. Attendre la mise à jour de GitHub Pages.
4. L'URL Pudu peut rester identique si elle pointe déjà vers ce dépôt.

IMPORTANT
- Pour les visiteurs, utilisez l'URL normale, sans ?admin=1.


VERSION FR/EN + ADMIN
- Choix Français / English sur l'accueil.
- Les mots anglais ont été adaptés pour être jouables sans accents.
- Triple-tap invisible dans le coin supérieur droit (3 appuis en moins de 2 s) ouvre Réglages Ketty.
- Accès de secours : ajouter ?admin=1 à l'URL.
- Réglages mémorisés : voix, effets sonores, musique.
- Le panneau indique si speechSynthesis est disponible dans le navigateur.
IMPORTANT : si la tablette affiche "Voix navigateur disponible : NON", il faudra utiliser des fichiers voix MP3 pour garantir la parole.
